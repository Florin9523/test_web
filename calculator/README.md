# Abac – calculator clasic și științific

Aplicație web pentru telefon (PWA): se instalează pe ecranul principal și merge și fără internet.

## Funcții
- **Clasic**: + − × ÷, %, ±, ștergere, `50+10%` = 55
- **Științific**: sin/cos/tan și inversele (2nd), ln, log, eˣ, 10ˣ, √, ∛, x², x³, xʸ, ʸ√x, x!, 1/x, |x|, π, e, EXP, Ans, Rnd, paranteze
- Grade / radiani (DEG / RAD)
- Previzualizare a rezultatului în timp ce scrii
- Istoric (atinge un rezultat ca să-l refolosești), atinge rezultatul pentru a-l copia
- Ține apăsat ⌫ pentru a șterge tot
- Temă luminoasă / întunecată automată

## Instalare pe telefon
1. Publică folderul pe GitHub Pages (Settings → Pages → Branch).
2. Deschide `https://<utilizator>.github.io/test_web/calculator/` pe telefon.
3. **Android (Chrome)**: meniu ⋮ → *Instalează aplicația* / *Adaugă pe ecranul principal*.
   **iPhone (Safari)**: butonul Distribuie → *Adaugă pe ecranul principal*.
